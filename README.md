Contoso PetFriends App is an app built in C# as part of a course to learn the language. This version of the app is the result of multiple chapter projects put together.

This app provides users with a main menu with three options. Entering "1" will display all pets and information lsited in the pre-defined array. Entering "2" will allow the user to then enter a pet characteristic and only display matching pets in the array. Entering "Exit" will exit the application.
